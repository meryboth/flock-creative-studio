# Brand kit de Flock

Fuente de verdad de la marca. **Todos los eventos la heredan y ningún agente puede modificarla.**

| Carpeta | Qué va | Formato preferido |
|---|---|---|
| `logos/` | Logo horizontal, isotipo solo, y cada uno en versión blanca, color y negra | **SVG** (si no hay, PNG transparente ≥ 4000 px) |
| `fonts/` | Tipografías institucionales | OTF/TTF/WOFF2 + licencia |
| `manual/` | Manual de marca | PDF |
| `elements/` | Patrones, íconos, ilustraciones propias, fotos aprobadas | SVG/PNG |

Después de agregar archivos, actualizar `brand.json` (variantes, fondo de uso, tamaño mínimo, área de resguardo).

Convención de nombres: `flock-{tipo}-{color}.svg`, por ejemplo `flock-horizontal-white.svg` o `flock-isotipo-color.svg`.
