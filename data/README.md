# Datos

- `nomina-ejemplo.csv`: nómina **ficticia** que se usa para credenciales y certificados mientras no haya una fuente real conectada. Ningún nombre corresponde a una persona de Flock.

La nómina real se va a leer de una fuente externa (por ejemplo, un Excel en SharePoint). Ver `packages/studio/src/roster.ts` y la sección de credenciales de `docs/PROPUESTA_TECNICA.md`.
